## Prompt

```text
I sell print-on-demand t-shirts on Etsy. Help me plan, not build yet. Make a plain-English map of a pipeline with these stages: niche research, research images, design generation, background removal, print prep, mockups, listing copy, publishing. For each stage, list what goes in, what comes out, and whether a human must approve it. I want exactly three human gates: niche, research images, designs. Put the plan in PIPELINE.md with one folder per stage and a CONTEXT.md in each. Don't write app code, don't use any API key, and ask me before installing anything.
```
